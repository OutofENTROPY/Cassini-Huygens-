# 引力弹弓 / SOI 进入弧镜像 bug 修复报告

日期：2026-10-01 · 范围：`tools/bake_data.py`（烘焙端）、`data/cassini_data.js` + `data/moons_data.js`（重烘焙）

## 1. 症状

所有引力弹弓（Venus-1 / Venus-2 / Earth 飞掠）与进入行星引力范围后的相对轨迹弧线
**绕行方向整体相反（镜像）**：入射弧到达行星后，绕行弧从行星错误的一侧绕过，
与入射方向呈大角度折角。README「已知问题」中挂账的"飞掠段渲染/插值 bug"即此。

## 2. 根因

NASA Eyes dynamo 的**飞掠腿（sc_cassini/venus/flyby1|2、earth/flyby）、发射逃逸腿
（sc_cassini/earth/launch）与惠更斯 Titan 进入腿（sc_huygens/titan/orb）的圆锥
曲线元素相对真实轨迹整体镜像/定向虚构**：
用巡航腿（sun/N，远离行星处为真实历表）实测的入射/出射行星系速度算出真实转弯
平面法向 h_true，再与腿根数外推的双曲线角动量 h_conic 对比：

| 腿 | ∠(h_conic, h_true) | 速度方向 vs 真实 |
|---|---|---|
| Venus-1 (1998-04-26) | **179.15°** | 入臂 108.3° |
| Venus-2 (1999-06-24) | **179.76°** | 入臂 138.4° |
| Earth (1999-08-18) | **179.76°** | 入臂 160.3° |
| Huygens→Titan (2005-01-14) | **179.9°**（对巡航接近方向） | 接近方向夹角 154.7° |
| **Launch (1997-10-15)** | （同族定向缺陷） | **出臂 ~78–84°**（相对 sun/1 推出的真实出射方向） |
| **Saturn/orb 入臂 (2004-05-30..07-01)** | **172°→180°**（对 SPICE 真值，6 月全程） | 首键帧当日位置差 **11,947,264 km** |

腿根数中**只有近掠距离 rp 与近拱点时刻 t_peri 是真实任务值**（V1 6,336 km
@13:45 UTC、V2 6,652 km @20:30、Earth 7,550 km @03:29、Launch 6,645 km @09:17
≈入轨近地点，均与任务实录/轨道根数一致），方向不可用。旧 `rebuild_flyby`
直接外推该镜像双曲线 → 绕行方向反转；launch 腿直接渲染 → 逃逸段画到错误一侧，
与 sun/1 真实弧形成倒钩（发射后视图中已飞/未来轨迹在探测器处呈反折）。

不受影响的段（核对确认无需修改）：
- **Jupiter 飞掠**：由 sun/4 腿真实根数插值，∠(h_trail, h_true)=0.0°；
- **Saturn 捕获后环绕段**（2004-07-02 起）：真实 saturn/orb 腿（NAIF SPICE 验证
  ≤1.5k km）——但该腿 **2004-05-30 起的入臂接近段为镜像伪造**（见 §3.2，
  初判"Saturn SOI 螺旋无镜像"仅对捕获后段成立，系误判，NASA Eyes 对比证实）。

## 3. 修复方案（`rebuild_flyby` 重写）

由「真实状态 + 真实近拱点」构造正确的行星中心双曲线（黄道系，μ 取 def.dyn 头
NASA Eyes 同源值）：

1. 轨道面 ĥ = unit(v_in × v_out)：v_in/v_out 取巡航腿在 SOI 穿越时刻的行星系速度；
2. 转弯角 δ = ∠(v_in, v_out)（方向测量最稳）→ e = 1/sin(δ/2)；A = rp/(e−1)，
   近拱点 rp 钉腿根数真实值；
3. 入射渐近线 = 实测 v(SOI) 回退 bend(SOI)（双曲线到 SOI 边界已累积的**速度方向**
   转弯，~0.03°；注意 ≠ 真近点角差 ~1.1°），使边界与真实入射弧严格相切；
4. 近拱点时刻 t_peri 取腿关键帧（任务实录值）；
5. 2.5×SOI 权威窗口 + 外移漂移过渡（原机制保留：B = δ_pos/2.5 km/s，钳 2–10 天）。

惠更斯 Titan 进入弧同理：A/e/t_peri 取进入腿关键帧（真实），ĥ/v̂∞ 取巡航腿
（sc_huygens/saturn/orb）在 Titan 远场（−48h，SOI 外 ~22×）的方向。

### 3.1 发射逃逸段（`build_launch_escape`，2026-10-01 补）

launch 腿与飞掠腿同族但签名不同：径向剖面、能量与近拱点均为真实任务值
（v∞=4.089 km/s → C3=16.72 vs 实测 16.60 km²/s²；rp=6,645 km≈入轨近地点；
首帧 r=8,284 km @ 09:27 与根数自洽），但速度方向偏 ~78–84°。与飞掠的差异：
逃逸弧只有出臂（无入臂可测），且腿边界 t_b（1997-10-18 16:01，r_rel=124 万 km）
在地球 SOI（92.5 万 km）之外——该处状态向量反解的密切 rp（7,868 km）被日心
摄动污染，不能钉近拱点。构造改为：

1. ĥ = unit(r_rel × v_rel)、v∞² 能量反解、e = 1 + rp/A——均取 sun/1 在 t_b 的
   真实地球系状态；
2. 渐近线 = 实测 v̂(t_b) 沿 ĥ 前旋剩余转弯 ψ（~0.6°；出臂公式与飞掠入臂互为
   镜像：P = −(v̂∞ + √(e²−1)·ĥ×v̂∞)/e，符号数值自检取边界方向差最小者）；
3. rp/t_peri 钉腿根数（入轨近地点任务值）；
4. 边界处 ~3,938 km 径向残差（密切根数外推所致）由 merged/seg 末端 36h
   混合窗平滑吸收（混合速率 0.03 km/s ≪ 真实 4 km/s；SOI 显示窗在混合窗之外，
   锚定一致性不受影响）；
5. 近拱段加密：merged 60s（近拱 +2h）/300s（+12h）/600s；模型 seg 150s 均匀网格；
   launch→sun/1 的旧 48h 交叉淡化拼接（会对错误腿做混合）移除。

### 3.2 土星 SOI 接近段（`build_saturn_approach`，2026-10-01 补，NASA Eyes 对比发现的镜像）

用户以 NASA Eyes 对比发现"进入土星引力范围时轨道镜像"。SPICE 仲裁
（`tools/check_sat_approach.py`，IMCCE Miriade/NAIF -82 独立真值）证实：

- sun/4 巡航腿（2004-03..05-30）真实：日心误差 ≤18 万 km（0.5%）；
- saturn/orb 腿入臂（首键帧 2004-05-30 20:01 起，e>1 双曲线帧）**整体镜像**：
  ∠(h_leg, h_true) 6 月全程 171.7°→179.93°（反平行），∠(P_leg, P_true)
  0.4°–7°（近拱点方向一致）——与飞掠腿完全同族；首键帧当日 SPICE 位置差
  11,947,264 km，6 月沿镜像弧进入（7-01 仍差 39.9 万 km），7-02 起捕获段真实
  （≤1.5k km）；
- 旧版另以 30 天交叉淡化拼接 sun/4→saturn/orb（边界 gap 11,998,793 km），
  2004-04-30..05-30 的路径是真实弧与镜像弧的捏造混合（峰值误差 1,260 万 km）；
- rp/t_peri 为真实任务值：rp=80,284 km、t_peri=2004-07-01 02:39:11（腿根数，
  与 SPICE 扫描近拱一致）。

构造（发射段配方 + 一项改进）：

1. ĥ = unit(r_rel × v_rel)、v∞² 能量反解、e = 1 + rp/A——取 sun/4 在两腿交界
   t0（= saturn/orb 首键帧，|r|=1,724 万 km）的真实土心状态；
2. 入臂渐近线反解 P = (v̂∞ − √(e²−1)·ĥ×v̂∞)/e（rebuild_flyby 同式，符号自检）；
3. rp/t_peri 钉腿根数（e>1 帧限于入臂 90 天窗口内取 |M0| 最小——全腿 1,570 帧
   的环绕段每个近拱后都有 M0≈0 帧，不可全局取）；
4. **反解半长轴 A**（新）：太阳潮在 1,724 万 km 处累积 ~31 天，钉定构造的边界
   位置残差达 11.4 万 km（12.7h 混合窗吸收会产生 6.2°/h 假折角）。保持 rp/t_peri
   钉定不动，沿迹相位由 A 吸收（A 增大 → 平均运动减小 → t0 相位后移，单调二分）。
   SPICE 仲裁：边界残差 11.4 万 → <2.7 万 km，6 月中程误差 113k→12k 改善为
   **27k→11k km**，混合窗缩回 6h 下限、无假折角；
5. merged 窗口替换 [t0−W/2, t_peri+6h]：近端与 sun/4 真实弧平滑混合，远端
   t_peri+1h..+6h 混入 saturn/orb 真实捕获弧（SOI 点火 2004-07-01 01:12–02:48
   UTC 已完成，其后腿数据真实）；日心 = rel + planet32(t) 锚定语义同 rebuild_flyby；
6. sun/4→saturn/orb 的 30 天交叉淡化拼接删除（`SPLICE_W` 置空）；卫星近掠扫描
   起点钳至 t_peri+6h（其后腿数据才真实，避免镜像段误触卫星窗口写回 merged）。

## 5. 遗留（非本 bug，见 README 已知问题）

**土星 SOI 段的"发卡弯"观感（2004-07 视图）——已定性为数据缺陷并修复**：
初判（同日早前）曾将用户报告的 Cassini 附近 V 形折角归为"物理现象"（e≈0.98
捕获轨道近拱近径向、日心/相对两轨迹 ~6° 夹角叠加）。NASA Eyes 对比推翻该结论：
V 形的入臂一侧是 saturn/orb 腿的**镜像伪造弧**（§3.2），30 天拼接又把真实弧与
镜像弧捏合出 1,260 万 km 的虚假路径——"发卡弯"即真实弧与镜像/捏造弧的交叠。
修复后入臂自真实一侧进入，V 形消失；捕获轨道几何（e≈0.98、近拱 8.0 万 ×
远拱 920 万 km、近拱点近乎径向直上直下）仍为物理现象，与任务一致。
（保留的轻微观感：日心轨迹与 SOI 相对轨迹在探测器处的正常小夹角，NASA Eyes
同样存在。）

**木星飞掠深度**：sun/4 腿在木星近旁仅 3 个根数关键帧（~13 天间隔），插值近掠处
削角：轨迹最近 ~1,066 万 km（2000-12-29 20:15 UTC）vs 任务实录 ~979 万 km
（Icarus 论文 9,794,457 km @ 2000-12-30）。转弯/平面/SOI 状态正确（≤0.2°），
属源数据插值精度限制（NASA Eyes 自身渲染同样表现），未强行以任务锚点重构。

**轨迹数组 f32 量化噪声**：merged trail 以 f32 存储（日心距 ~13.5 亿 km 处
点位噪声 ~±160 km），深度放大时折线顶点方向有 ≤2° 级随机抖动（0.5h 弦长），
任何包含完整弧段的视图均低于一个像素；属项目数据格式的固有限制，与本次
修复无关（对照：巡航段同样存在）。
