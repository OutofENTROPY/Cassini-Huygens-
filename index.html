操作说明

  • 左键拖动 — 旋转视角
  • 滚轮 — 缩放
  • 右键拖动 — 平移视野中心
  • 点击行星 / 卫星标签 — 平滑过渡聚焦该天体
  • 点击时间轴圆点 / 事件列表 — 跳转事件并聚焦 Cassini
  • 时间条拖动 — 任意时刻回放（条左半为倒退半程，右半为快进半程）
  • 空格 — 播放 / 暂停
  • 时间条上方速率滑块 — 时间流速（中点保持，左=倒放，右=正放）
  • 右上角 ⛶ — 全屏显示 / 退出全屏
  • 右上角 ⚙ 设置 — 全局视角、真实光照、行星 / Cassini 轨迹开关、未来轨迹显隐、近期/全部历史轨迹切换

行星尺寸与轨道距离均为真实比例；Cassini 进入行星引力影响球（Venus / Earth / Jupiter / Saturn）时，自动叠加显示相对该行星的轨迹，两条轨迹的交点即 Cassini 实际位置，日心轨迹同步降低亮度；在土星系统内进一步接近卫星（Titan / Enceladus / Rhea / Dione / Iapetus 等）时，日心与土星相对轨迹再降亮度并淡入相对卫星的二级轨迹；离开影响球后自动淡出恢复。点击 Huygens 标签或事件卡可跟随惠更斯探测器（2005-01-14 着陆 Titan、失联后自动移除实体）。飞船模型为真实尺寸（缩小视角时随之缩至真实大小），高增益天线按任务实际姿态实时指向 Earth。
